# ANGEL SWARM — Slides

`UNCLASSIFIED // SYNTHETIC DATA // FOR DEMONSTRATION ONLY`

Two decks ship with this package. Both are 16:9, both are built in the same visual system as the application itself, and both are rendered here as PNG so they can be read on GitHub without downloading PowerPoint.

| Deck | Slides | Purpose | Rendered |
|---|---|---|---|
| [`ANGEL-SWARM-pitch.pptx`](ANGEL-SWARM-pitch.pptx) | 3 | The pitch: the problem, what it costs, what changes. | [`ANGEL-SWARM-pitch.md`](ANGEL-SWARM-pitch.md) |
| [`ANGEL-SWARM-leadership-opener.pptx`](ANGEL-SWARM-leadership-opener.pptx) | 3 | A shorter leadership opener — title, stakes, deliver. | [`ANGEL-SWARM-leadership-opener.md`](ANGEL-SWARM-leadership-opener.md) |

`slides/` holds a 90 dpi PNG of every slide, generated from the `.pptx` files in this folder. The `.pptx` is the source; the PNG and the Markdown are renderings of it.

Both decks state the same headline result as the application and the documents: **23 dead of survivable wounds against 34**, seed 42, PACOM CORAL, capability deployed — one draw from a distribution whose interval does not touch zero. The conditions travel with the number in every deck, on every slide it appears.
