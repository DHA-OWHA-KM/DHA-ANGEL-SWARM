---
name: Navigation hover treatment
description: The user-approved interaction style for destination menus.
---

Use a soft 220 ms ease-in/ease-out surface fade and make the destination icon clearly more prominent with a strong brightness lift and modest saturation increase. Avoid accent edges, glow, scaling, or abrupt movement. Keep the selected surface stronger than hover.

**Why:** The accent-edge prototype felt too assertive, while the first soft-fade version made the icon change too subtle. The user explicitly confirmed the stronger-icon soft fade as perfect.

**How to apply:** Use this treatment consistently for destination-menu hover and keyboard focus. Preserve reduced-motion behavior and each icon’s established hue.
